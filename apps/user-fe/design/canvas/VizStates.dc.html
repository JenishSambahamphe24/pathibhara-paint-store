How the 3D behaves
  • Picture first. A static image of the house (WebP, about 30 KB) shows instantly; the 3D view swaps in once the model loads.
  • Loads only when needed. The 3D code and the model load only on pages with the house, and only when it is near the screen.
  • Light on phones. Render resolution capped at 2×, one sun light plus soft sky light, soft shadows.
  • Pauses itself when the house scrolls off-screen or the tab is hidden.
  • Gestures: one finger turns, two fingers zoom, reset returns to the front corner view. Turning stops the slow auto-spin.
  • Reduced motion: no auto-spin, no flashes; the tapped part is named in the “Repainting” label instead.
  • Fallback: no WebGL, or the model fails to load → the drawing above, still repainting.
  • Colour honesty: plain, even lighting with no tone mapping, so the picked shade is shown as true as a screen allows.
