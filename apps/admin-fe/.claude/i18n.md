# Internationalisation (i18n)

Paraglide JS is the i18n solution. Supported locales: `en` (base). Nepali can be added later in `project.inlang/settings.json`.

## Never Hardcode Display Strings

All user-visible text must use the `m` helper from Paraglide.

```tsx
import { m } from "#/paraglide/messages";

// Correct
<p>{m.users_page_title()}</p>

// Wrong
<p>Users</p>
```

## Adding a New Message Key

Edit the base locale file only:

```
messages/en.json
```

Keys use `snake_case` and are grouped by feature prefix:

```json
{
  "users_page_title": "Users",
  "users_create_button": "Create User",
  "sidebar_users": "Users"
}
```

Common prefixes:

- `sidebar_` — sidebar navigation labels
- `dashboard_` — dashboard section labels
- `<feature>_` — everything else, namespaced by feature

After adding a key, the Vite dev server will auto-regenerate `src/paraglide/`. For a production build, run `pnpm build`.

## Auto-generated Files

Everything under `src/paraglide/` is auto-generated — **never edit it manually**.

## Dynamic Values in Messages

Use `{variable}` placeholders in the JSON and pass values as arguments:

```json
{ "current_locale": "Current locale: {locale}" }
```

```tsx
m.current_locale({ locale: getLocale() });
```
