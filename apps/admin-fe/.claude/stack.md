# Tech Stack

| Layer           | Library                                     |
| --------------- | ------------------------------------------- |
| Framework       | TanStack Start (`@tanstack/react-start`)    |
| Routing         | TanStack Router (file-based, `src/routes/`) |
| Server          | Nitro (nightly)                             |
| Data Fetching   | TanStack Query v5                           |
| Forms           | TanStack Form v1                            |
| UI Components   | **Ark UI** (`@ark-ui/react`)                |
| Styling         | Tailwind CSS v4 + `clsx`                    |
| Charts          | Recharts (added in Phase 4)                 |
| Tables          | TanStack Table v8                           |
| State           | TanStack Store                              |
| i18n            | Paraglide JS (output: `src/paraglide/`)     |
| Validation      | Zod v4                                      |
| Icons           | Lucide React                                |
| Testing         | Vitest (`vitest.config.ts`)                 |
| Package Manager | pnpm v10                                    |
